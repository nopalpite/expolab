Flasheur de cartes SD

Branche un lecteur de carte USB sur le serveur : l'image master est écrite, vérifiée, puis personnalisée pour la machine choisie.

Mode simulation : aucune carte réelle n'est écrite.

Carte

Aucune carte détectée.

Branche le lecteur USB avec la carte. Seuls les disques USB sont proposés : le disque du serveur n'est jamais affiché.

Sera écrit

    Tout le contenu actuel de la carte sera effacé.

      Envoyer une image

      Un master compressé (.img.xz, .img.gz, .img.zst) ou brut (.img). L'envoi peut durer plusieurs minutes : garde cette page ouverte.

      Réglages écrits sur chaque carte

      Appliqués à chaque flash. Les mots de passe restent sur le serveur : ils ne sont jamais renvoyés à cette page, et seul le mot de passe du compte, haché, est écrit sur la carte.

      Compte utilisateur

      Sans compte défini ici, l'image Ubuntu n'a aucun moyen de connexion : son compte par défaut est créé sans mot de passe.

      Serveurs de l'expo

      Ce que les machines utilisent sur le réseau de l'expo. Sur un autre réseau (la maison), le serveur de temps est simplement ignoré, mais un proxy apt injoignable empêcherait apt de fonctionner : laisse-le vide hors expo.

      Clavier, langue et heure

      Pour un clavier branché sur la machine. Vide = réglage de l'image (qwerty, anglais, UTC).
