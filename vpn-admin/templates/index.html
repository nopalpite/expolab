Adresse publique du VPN

Adresse à laquelle un poste situé hors de ton réseau joint ce serveur : l'IP publique ou, mieux, un nom DNS (DDNS) qui pointe dessus, avec le port que ton routeur redirige vers ce Pi (UDP 51820 par défaut). Les nouveaux pairs l'utilisent ; sans elle, ils visent l'IP locale du Pi, inutilisable à distance.

Une config déjà importée sur un poste garde son ancienne adresse : redonne-lui la config mise à jour (.conf ou QR). Il faut aussi rediriger le port UDP du routeur vers ce Pi.
