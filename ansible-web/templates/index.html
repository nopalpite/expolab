Programmes par machine

Chaque machine affiche un programme en plein ecran (role kiosk). Choisir un programme et une version enregistre l'association ; Installer lance un run sur la machine (il passe par la file). Une machine flashee par l'exploitant recoit aussi son programme pendant son installation automatique.

Version voulue : une release precise (figee) ou « derniere » (la plus recente au moment du run). Installee : ce qu'un run a reussi a poser sur la machine. Une machine sans tag kiosk peut recevoir un programme, mais rien ne l'affichera a l'ecran.
